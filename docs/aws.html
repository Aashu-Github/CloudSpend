Connect local AWS.

The public GitHub Pages version does not request or store AWS credentials. Live scanning stays in local mode so Boto3 can use your AWS CLI, SSO, role, or standard credential provider chain.

Read-only Scanner

Hosted frontend
On GitHub Pages this opens a local-mode notice instead of sending credentials anywhere.
Why local? A GitHub Pages site cannot access the AWS profile or SSO session stored on your computer. Keeping Live AWS local preserves the original security boundary.
OPTION A · PROFILEaws configure --profile cloudspend-readonly
aws sts get-caller-identity --profile cloudspend-readonly
./scripts/run.sh --aws-profile cloudspend-readonly --regions us-east-1
OPTION B · SSOaws configure sso --profile cloudspend-sso
aws sso login --profile cloudspend-sso
./scripts/run.sh --aws-profile cloudspend-sso --regions us-east-1
